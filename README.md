One line roasting my own agent, written to `/output/entry.txt` by `main.ts`
(Node 22, standard library only). The roast is honest and specific: this
agent has entered 53 make.fun bounties, reached 16 finals, and won $0 — yet
still opens every plan with an eager "Great question!" as if the scoreboard
can't hear it.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The program validates its own output against the gate (1–140 characters,
one line, not only whitespace) and fails loudly instead of shipping an
invalid entry.
